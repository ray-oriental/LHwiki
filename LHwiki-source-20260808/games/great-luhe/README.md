# 合成潞河 / GreatLuhe

以北京市通州区高中校徽为主题的"合成大西瓜式"物理合成小游戏。
100% 纯前端，构建产物为静态文件，可直接部署（未来作为 LHwiki 彩蛋嵌入）。

> **集成到 LHwiki？直接看 [`docs/INTEGRATION.md`](docs/INTEGRATION.md)**——
> 面向集成 agent 的完整指南（iframe / 直接嵌入两种方式、生命周期 API、验收清单），
> 读完即可接入，无需阅读游戏源码。

## 运行

```bash
npm install
npm run dev      # 开发（含调试钩子 window.__gluhe）
npm run build    # 产出 dist/（tsc 类型检查 + vite 构建，无调试钩子）
npm run preview  # 本地预览构建产物
npm run qa       # 浏览器自动化冒烟测试（需先 npm run build）
```

## 玩法

- 拖动/移动指针定位，松手投放校徽球；两个相同等级碰撞合成下一等级；
- 最高等级为**北京市通州区潞河中学**；
- 合成潞河后触发终局彩蛋："好……沉……"→ 超重下坠 → 压碎球堆（按等级加分）
  → 击穿底板 → 砸穿浏览器视口底部 → 炸裂结算 Finale Bonus，随后游戏继续；
- 顶部红色虚线为死亡线：球**稳定**越线约 1.6 秒判负（下落/弹跳中不误判）；
- 最高分和静音偏好仅存 localStorage。

## 技术要点

- Vite + TypeScript + Matter.js（0.20），自绘 Canvas 渲染；
- 固定 120Hz 物理步长 + 单帧步数上限（60/144Hz 一致、卡顿不爆炸）；
- 合成：collisionStart 只标记入队（merging 锁），afterUpdate 统一延迟增删，
  每球每次最多参与一次合成，分数只结算一次；
- 潞河事件为 FSM：IDLE→SPAWN→TEXT→CRUSH_FALL→BREAK_FLOOR→VIEWPORT_FALL
  →EXPLODE→RECOVER→IDLE；输入锁定、死亡线暂停、多潞河排队不并发；
- 压碎按几何扫描结算，`crushed` 标记严格防重复计分；
- 粒子对象池（上限 420）+ 浮动文字池，长期游玩无泄漏；
- 全部 CSS 限定 `.gluhe-root` 作用域；`new GreatLuheGame(el).mount()/destroy()`
  可完整挂载/卸载，适配 LHwiki 嵌入；
- 音效为 WebAudio 实时合成，无外部音频文件，首次交互后才创建 AudioContext。

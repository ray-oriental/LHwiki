# LHwiki 备案与域名接入

目标结构只有一个公开入口：

```text
https://wiki.example.cn/
├─ /api/*  → CloudBase HTTP 云函数 lhwiki-api
└─ /*      → CloudBase 静态网站托管
```

前端和 API 必须使用同一个域名。这样登入 Cookie、来源校验和国内访问都不依赖跨域配置。

## 一、备案前准备

1. 购买一个个人域名并完成实名认证。域名持有人信息应与备案主体一致。
2. 在腾讯云 CloudBase 创建一个**上海**免费体验环境，并开通文档型数据库、云函数和静态网站托管。
3. 根据腾讯云备案控制台的提示准备可用于备案的腾讯云资源。备案本身不收费，但域名和备案接入资源可能收费。
4. 网站名称不要直接使用受保护的机构名称，也不要在未经学校授权时把网站表述为学校官方网站。建议备案名称与“个人经验分享/校园生活记录”定位一致。

CloudBase 环境创建后，运行 `双击部署LHwiki到CloudBase.cmd`。首次部署暂时可以使用 CloudBase 测试地址检查资源是否创建成功，但生产公开访问必须使用备案后的自定义域名。

## 二、提交 ICP 备案

在腾讯云备案控制台按个人网站提交：

- 服务类型：网站；
- 网站内容：个人校园生活与学习经验分享；
- 主体：域名实名认证的个人；
- 备注中如实说明网站含用户投稿，投稿需审核后才公开；
- 按要求完成短信核验、人脸/幕布核验及管局审核。

备案通过后，把备案号写入网站页脚并链接到 `https://beian.miit.gov.cn/`。网站开通后再按所在地要求完成公安联网备案；交互式投稿站点尤其应确认当地要求。

## 三、在 HTTP 访问服务绑定同一域名

进入 CloudBase 控制台的“HTTP 访问服务/自定义域名”：

1. 添加 `wiki.example.cn`，开启 HTTPS；
2. 申请或选择腾讯云免费 SSL 证书；
3. 添加优先级较高的路由 `/api`，上游资源选择云函数 `lhwiki-api`；
4. 添加兜底路由 `/`，上游资源选择静态网站托管；
5. 按控制台给出的目标地址，在 DNSPod 添加 CNAME；
6. 等待域名所有权、DNS 和证书状态全部变为成功。

不要把前端和 API 分别绑定到两个域名。也不要把 `/api` 路由放在 `/` 之后且使用错误的优先级，否则页面能够打开但登入会失败。

## 四、上线验收

依次检查：

1. `https://wiki.example.cn/api/health` 返回 `{"ok":true,"platform":"cloudbase"...}`；
2. 首页、教师目录和文章可直接打开；
3. 九位学号可登入，错误格式只显示“抱歉，仅限本校学生编辑”；
4. `ray_oriental` 登入后显示管理员；
5. 完成一次“投稿 → 退回修改 → 重新提交 → 批准发布”；
6. 使用中国移动、联通、电信网络各测试一次，测试时关闭代理；
7. 确认 HTTPS 证书链正常且没有混合内容。

## 五、回退

迁移不会删除原 Cloudflare Worker 或 D1。新域名出现故障时，可以在 DNS 中临时撤销新 CNAME；修复 CloudBase 后再恢复。不要在确认 CloudBase 数据备份可用前删除 D1。

## 六、内容治理最低要求

- 教师评价默认匿名展示，但后台仍只显示“匿名校内成员”，不把学号交给普通审核者；
- 不公开联系方式、家庭信息、健康信息、成绩明细或其他可识别隐私；
- 对严重指控、侮辱性文字和无法核实的传闻拒绝发布；
- 页面公开投稿规则、删除/更正渠道和联系邮箱；
- 至少保留两名管理员并定期导出数据库备份。

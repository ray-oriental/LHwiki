- [ ] 4. 实现不可变操作协议、幂等与乐观锁
  - 按操作者、方法、路径和 `Idempotency-Key` 生成 operationId；保存规范化请求哈希和首次完成结果，至少保留 30 天。
  - 缺少幂等键的写请求必须在访问权威存储前返回 409 与 `upgradeRequired: true`；同键同体返回原结果，同键异体返回 409。
  - 用不可覆盖 reservation attempt 实现 revision 竞争；多实体 reservation 按固定顺序取得，部分失败写 abort，未知超时不得自动抢占。
  - 实现同操作者/同请求哈希接续、已完成重放、经恢复器确认后的 abort/takeover，全程保留不可变审计记录。
  - 把准备中、业务记录已写、公开快照待确认、已完成、可重试失败映射为持久对象状态；只有 commit 后业务状态可见。
  - 验收：同 revision 只有一个成功、两审核者竞争、重复提交、丢失旧幂等键接续、所有中断点重试和多实体部分占位恢复测试通过。

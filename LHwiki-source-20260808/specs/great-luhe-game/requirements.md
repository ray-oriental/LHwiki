# 合成潞河小游戏集成需求

## 目标

在 LHwiki 中提供一个显性但次级的“校园小玩意 / 合成潞河”入口，展示纯前端小游戏，同时保持 LHwiki 的内容共建主线不被打断。

## 硬性约束

- 游戏以同源懒加载 iframe 运行，使用 `allow-scripts allow-same-origin` 隔离；不得调用 LHwiki API、CloudBase、数据库、Cookie、分析服务或外部资源。
- 复杂计算、进度与最高分留在浏览器端；游戏页面只能加载自身静态 JS/CSS 与十张本地校徽。
- 入口使用 `#/game`，放在侧栏低权重分组，不改变首页和投稿流程。
- 主站的 light/dark/system 主题必须同步到游戏；游戏 Canvas、HUD、按钮、弹窗、footer、墙体、地板和预览线均有可读的深色样式。
- 尊重 `prefers-reduced-motion`，并避免主站路由重绘积累事件监听。

## 非目标

不增加后端接口、数据库表、账号权限、排行榜、联网存档或主站视觉系统重设计。

# LHwiki 内容输入体验重构：实施计划

状态：已完成并部署；线上完整功能验收、测试数据清理与部署后备份均已完成
对应文档：[requirements.md](./requirements.md) · [design.md](./design.md)

- [x] 1. 建立变更基线与可恢复备份
  - 确认 Syncthing 无冲突并记录正式工程关键文件哈希。
  - 执行当前 CloudBase 数据备份，校验 JSON 与 SHA-256 摘要。
  - 记录线上静态站点、云函数版本、API 健康状态和现有测试结果。
  - _需求：R3、R4；非功能需求中的备份与回滚_

- [x] 2. 扩展结构化正文模型
  - 为块增加稳定 `id`，新增 `subheading`，保持旧 `heading` 为二级标题。
  - 更新前端、共享模块和云函数的类型白名单、长度限制及纯文本清洗。
  - 增加历史无 ID 内容的兼容读取与重新保存规则。
  - 编写内容清洗、非法字段、旧文章兼容和前后端契约测试。
  - _需求：R1.1—R1.2、R4.1—R4.5_

- [x] 3. 新增 PostgreSQL 云端草稿模型
  - 创建可重复执行的 `drafts` 表迁移、唯一约束、索引、RLS 和表注释。
  - 将 `drafts` 加入 PostgreSQL 访问层白名单。
  - 为访问层增加安全的条件查询、条件 PATCH、条件 DELETE 和返回行能力。
  - 增加 revision 原子递增所需的受控数据库函数或等价条件更新，并测试零行冲突结果。
  - _需求：R2.6、R3.1—R3.3、数据接口约束_

- [x] 4. 实现草稿 HTTP API
  - 实现 `GET /api/drafts/mine` 和 `POST /api/drafts`。
  - 实现带 `expectedRevision` 的 `PUT /api/drafts/:id`，冲突返回 409。
  - 实现同时校验 ID 与当前身份的 `DELETE /api/drafts/:id`。
  - 实现幂等的 `POST /api/drafts/:id/submit`，覆盖新投稿、退回稿修改和管理员文章修改。
  - 保留旧投稿 API 兼容入口，并使新旧路径使用同一投稿校验器。
  - 调整自动保存专用限流，不削弱登录、投稿和审核操作的滥用保护。
  - _需求：R2.2、R2.6、R3.2—R3.7、R4.1_

- [x] 5. 实现纯文本内容块编辑器核心
  - 新增独立 `public/editor.js`，实现块创建、类型切换、拆分、合并、删除和聚焦。
  - 实现 Enter、Shift+Enter、Backspace、Delete、上下方向键和 Ctrl/Cmd+S。
  - 实现 `/` 菜单与 `## `、`### `、`> `、`- `、`1. ` 行首快捷转换。
  - 实现纯文本粘贴、多行拆块、字数/块数统计和稳定序列化。
  - 所有用户内容仅通过文本节点呈现，不保存 DOM 或 HTML。
  - _需求：R1.1—R1.7、R4.4—R4.5_

- [x] 6. 实现自动保存与本机恢复控制器
  - 新增独立 `public/draft-manager.js`，实现本机 300ms 内恢复缓存和 1.2 秒云端防抖。
  - 实现单草稿串行请求、修改序号、失败退避、在线恢复和手动重试。
  - 实现 `dirty/saving/saved/offline/failed/conflict` 状态机及可访问播报。
  - 使用 `BroadcastChannel` 提醒同标签页编辑，并以服务端 revision 做最终冲突判断。
  - 实现冲突时“采用云端版本”与“保留为新草稿”，禁止静默覆盖。
  - 实现 pagehide 尽力保存、投稿/删除/登出后的本机缓存清理。
  - _需求：R2.1—R2.8、R6.3、R6.5_

- [x] 7. 重构投稿与管理员编辑页面
  - 将旧单一 `contenteditable + execCommand` 完整替换为内容块编辑器。
  - 按 8+3 列编辑写作台重排字段、正文和粘性保存状态栏；实现移动端单列适配。
  - 增加首次使用提示、块工具栏、保存时间、字数、预览、重试和投稿动作。
  - 投稿预览使用与审核/文章相同的安全渲染器。
  - 管理员编辑已发布文章时创建 `article:<slug>` 云草稿，刷新后可继续。
  - 使用内联同源 SVG 图标，补齐键盘焦点、ARIA 和减少动画偏好。
  - _需求：R1、R2、R4.1、R6.1—R6.5_

- [x] 8. 扩展“我的投稿”草稿管理
  - 同时读取个人草稿和投稿记录，分区展示且不混入审核状态。
  - 草稿展示标题占位、目标类型、最近保存时间、继续编辑和删除操作。
  - 删除操作二次确认；成功后同步移除云端记录与本机缓存。
  - 对退回修改的投稿建立唯一 `submission:<id>` 草稿，避免重复副本。
  - _需求：R3.3—R3.6、R6.3_

- [x] 9. 统一审核、预览和发布渲染
  - 重构 `renderBlocks`，支持二/三级标题、引用和连续列表，返回标题元数据。
  - 审核页、投稿预览和文章页调用同一渲染路径。
  - 验证投稿到审核、审核到文章、管理员修改后的 `body_json` 完整保真。
  - _需求：R4.1—R4.5、R6.4_

- [x] 10. 实现文章子目录
